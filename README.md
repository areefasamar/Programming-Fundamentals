# Programming Fundamentals 🚀

Welcome to my **Programming Fundamentals** repository! This repository serves as a comprehensive archive of my foundational journey in computer science, featuring structured weekly lab assignments and a core **Complex Computing Problem (CCP)** project. 

The primary goal of this coursework was to transition from conceptual problem-solving to writing highly optimized, logical, and modular code (primarily in **C**).

---

## 🛠️ Tech Stack & Tools

* **Language:** C 
* **Compiler:** GCC / G++ 
* **Development Environment:** Dev-C++ / VS Code  
* **Concepts Covered:** Procedural Programming, Control Structures, Modularization, Arrays, Pointers, File I/O, and Memory Management.
